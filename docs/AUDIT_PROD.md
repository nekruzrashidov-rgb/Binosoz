# Аудит прода Binosoz — сайт, API и код

## 1. Итог

- **Дата:** 20.11.2026.
- **Версии:** сайт `v 80d4531` (футер, `/version.txt`), API `80d4531` (`/health/live`, сборка 20.11.2026 11:45 UTC). Сайт и API на одном коммите.
- **Где смотрел:** сайт https://binosoz.vercel.app, API https://binosoz-1.onrender.com, код ветки `fix/guest-booking-ip` (= `main` 80d4531). Роли проверял на локальном стенде (localhost:5194, Development).
- **Как:** curl (только GET и заведомо неверные POST), Playwright (обход 16 адресов × 3 языка, 7 ширин, axe-core 4.10 в светлой и тёмной теме, клавиатура, CLS), Lighthouse 12 (mobile и desktop), чтение кода, `dotnet build`/`dotnet test`, `gh` (CI, переменные — только имена).
- **Безопасность проверки:** на проде ничего не создано. Был один POST — бронь с пустыми полями (`POST /apartments/{id}/bookings` → **400**, сервер ничего не записал, см. A-17). Регистраций, заявок, кодов, подбора PIN и нагрузки не было.

**Минусов: 33** — Критично 0 · Высокий 5 · Средний 13 · Низкий 15.

**Пять самых важных:**
1. **A-02** — бэкапов прод-базы нет: `BACKUP_AGE_RECIPIENT` не задан, миграции 80d4531 прошли на проде **без бэкапа**, ночной «Backup prod» сегодня упадёт.
2. **A-01** — 4-комнатные квартиры (118,5 м²) подписаны на сайте как «3-комнатная»; в 3D те же квартиры — «4-комн.».
3. **A-03** — на проде включён тестовый банк (`/payment/mock/status` → `enabled: true`) и вход демо-покупателя паролем: «оплата» тестовой картой создаёт настоящий платёж в графике и в отчётах.
4. **A-04** — «Сдача 2026» / «2026 · год сдачи» на главной и в «О проекте» при готовности стройки 0% и пустом ходе стройки (ноябрь 2026) — без пометки «Демо-данные».
5. **A-05** — холодный старт API **36 с**; Keepalive по расписанию «каждые 10 минут» на деле запускается 1–2 раза в сутки.
