# Данные окружения 3D-модели

Файлы `context-<buildingId>.json` в этой папке — окружение дома для 3D-модели сайта: контуры и высоты соседних зданий,
дороги, парки и места рядом (школы, детсады, парки, медицина, мечети, магазины, остановки).

- **Источник:** OpenStreetMap, выгрузка через Overpass API скриптом `frontend/tools/context/build.mjs`.
- **Лицензия:** Open Database License (ODbL) 1.0. © участники OpenStreetMap — https://www.openstreetmap.org/copyright
- Подпись «© участники OpenStreetMap, ODbL» показывается в 3D-режиме сайта, пока окружение на экране.
- Файл строится только для дома с координатами (`PUT /buildings/{id}/location`); сайт к Overpass не обращается.
- Расстояния до мест сайт считает сам, по прямой от координат дома.

Сейчас файлов нет: у дома ещё не заданы координаты.
