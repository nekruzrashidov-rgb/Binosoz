# Sitora — фронтенд

Одно приложение на React 19 + TypeScript + Vite, три раздела:

| Раздел | Адрес | Для кого |
| --- | --- | --- |
| Сайт | `/`, `/building/:id`, `/floors/:id`, `/apartments`, `/apartments/:id`, `/contacts` | гости: выбор квартиры на 3D-модели, бронь на 48 часов, заявка |
| Личный кабинет | `/cabinet` | покупатель: вход по SMS, платежи, график, документы, чат, стройка |
| CRM | `/crm` | сотрудники: обзор, воронка, заявки, шахматка, сделки, клиенты, отчёты, курс, каталог, стройка, журнал, сотрудники |

Стек: Tailwind CSS 4, motion (анимации), TanStack Query (запросы и кэш), React Router 7, three.js / @react-three/fiber (3D-дом), SignalR (чат), lucide-react (иконки).

## Запуск

Сначала запустите API (`dotnet run` в `src/Sitora.WebApi`, порт 5194), затем:

```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```

Откройте http://localhost:5173. Vite проксирует `/api`, `/hubs` и `/health` на API, поэтому CORS в разработке не нужен. Другой адрес API — через переменную `SITORA_API`.

`--legacy-peer-deps` нужен из-за необязательных зависимостей `@react-three/fiber` под React Native.

## Сборка

```bash
npm run build
```

Готовые файлы — в `dist/`. На сервере их отдаёт веб-сервер (например, Caddy), а `/api` и `/hubs` проксируются на API — тогда сайт и API на одном домене и CORS не нужен.

## Что заполнить перед запуском

- `src/config.ts` — телефон, почта и часы офиса продаж (сейчас заглушки).
- 3D-модель: пока у дома нет `ModelUrl`, сайт строит дом по этажам каталога.

## Устройство

- `src/api` — типы (один в один с DTO бэкенда), HTTP-клиент с обновлением токена, все запросы.
- `src/components/ui` — кнопки, поля, окна, уведомления, таблицы, бейджи, скелетоны.
- `src/site`, `src/cabinet`, `src/crm` — разделы; `src/shared` — общие блоки кабинета и CRM (график, документы, чат, стройка, этапы сделки).
- Сессии сотрудника и покупателя хранятся отдельно, поэтому менеджер может открыть кабинет, не выходя из CRM.
- Права в CRM повторяют серверные (`src/crm/access.ts`); сервер всё равно проверяет их в каждом запросе.
