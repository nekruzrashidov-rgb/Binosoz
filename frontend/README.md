# Sitora web (фронтенд)

Сайт с 3D-домом, кабинет покупателя и CRM на чистом JavaScript, без сборки: `index.html`, `js/*.js`, `css/styles.css`.

## Запуск

Сначала API (`dotnet run` в `backend/src/Sitora.WebApi`, порт 5194), затем из корня репозитория:

```bash
node scripts/serve-web.mjs 5500
```

Откройте http://localhost:5500. Подойдёт и Live Server в VS Code на порту 5500. Проще всего запустить API и сайт вместе: `run.cmd` в корне репозитория.

## Настройки — `js/config.js`

- `API_BASE` — адрес API. По умолчанию пустой: сайт открывается в демо-режиме, адрес API (например, `http://localhost:5194/api/v1`) вводится на самой странице: шестерёнка внизу справа, значение сохраняется в браузере.
- Пустой `API_BASE` — **демо-режим**: встроенный бэкенд `js/mock.js`, сервер не нужен. Код всегда `123456`, для любой почты; незнакомая почта становится покупателем. Создатель платформы в демо — `nekrashidov@gmail.com`, входит одним кодом.
- `ORG_SLUG` — короткое имя застройщика, чьи дома и курс показывает публичный сайт (`sitora` — организация по умолчанию). Пустое — дома всех застройщиков платформы.
- `CONTACT` — телефон, Telegram, адрес и часы офиса продаж. Сейчас это заглушки, замените настоящими.

На сервере адрес сайта должен быть в `Cors__AllowedOrigins`. В Development уже разрешены `http://localhost:5500` и `http://127.0.0.1:5500`.

## Вход и роли

- Все входят одной формой: почта → код из письма. Создатель платформы после кода вводит пароль или код из приложения-аутентификатора. В Development с `Email__Provider=Dev` код пишется в лог API.
- После входа раздел выбирается по `user.role`: создатель платформы — «Платформа» (`#platform`), владелец, админ объекта и должности — «Управление» (`#crm`), покупатель — кабинет.
- В режиме «войти как владелец» сверху жёлтая полоса с кнопкой «Выйти из режима».
- Сотрудников приглашают из раздела «Сотрудники». Ссылка из письма ведёт на `#invite=<токен>` (адрес задаёт `Email__InviteUrl`, например `http://localhost:5500/#invite=`).

## Устройство

- `js/api.js` — слой API: мапперы `S.map.*` и методы `S.api.*`. Только этот файл знает имена полей сервера. Сверка с сервером — `docs/API_CONTRACT.md`.
- `js/site.js`, `js/cabinet.js` (вход, приглашение, кабинет), `js/crm.js`, `js/platform.js` — разделы; `js/panels.js` — общие блоки (график, документы, чат, стройка).
- `js/house3d.js` — 3D-дом (three.js), квартиры окрашены по статусам.
- `js/i18n.js` — тексты на русском и таджикском. Таджикские тексты стоит проверить носителю языка.
